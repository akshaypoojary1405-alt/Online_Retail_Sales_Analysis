Online Retail Sales Analysis

 ![Online Retail Sales Dashboard](Online_Retail_Sales_Dashboard.png)

Project Overview

This project analyzes an online retail dataset to understand sales performance, customer purchasing behaviour, product performance, and country-wise revenue.

The objective is to identify useful business insights using SQL and Power BI.

Tools & Technologies

- Excel – Data cleaning and preparation
- MySQL – Data analysis and SQL queries
- Power BI – Dashboard development and visualization

Dataset

The dataset contains online retail transaction details, including:

- Invoice Number
- Stock Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country
- Sales

Key Performance Indicators

- Total Sales: ₹9.49M
- Total Orders: 9,310
- Total Customers: 2,686
- Average Order Value: ₹1.02K

Key Analysis

1. Monthly sales trend analysis
2. Top 10 products by sales
3. Country-wise sales performance
4. Repeat vs one-time customer analysis
5. Sales contribution by customer type
6. Customer purchasing behaviour
7. Missing Customer ID analysis

Key Business Insights

- December 2010 recorded the highest monthly sales in the dashboard.
- Regency Cakestand 3 Tier was the top product by revenue.
- Repeat customers contributed more sales than one-time customers.
- Repeat customers represented approximately 48.5% of identified customers.
- The United Kingdom was the leading country by sales.
- Transactions with missing Customer IDs contributed approximately ₹1.57M in sales. These transactions were excluded from customer-type analysis but retained in overall sales calculations.

Dashboard

Developed an interactive Power BI dashboard with:

- KPI cards
- Monthly sales trend
- Top 10 products
- Sales by country
- Customer type analysis
- Country and date slicers

Conclusion

This project demonstrates practical skills in data cleaning, SQL querying, data analysis, DAX measures, and Power BI dashboard development. The insights help understand sales trends and customer behaviour.
